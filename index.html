About this ePortfolio

In plain English: A capstone is the final project of a degree. For mine, I took three projects I had built in earlier classes, improved them, and documented the changes the way a developer would at work.

This ePortfolio brings my coursework together into one professional collection. Each artifact started as a working project from an earlier course. For the capstone, I evaluated it, planned improvements, carried them out, tested them, and wrote a narrative explaining what changed and why.

Software engineering and design

Travlr Full Stack Application

In plain English: Travlr is a travel booking website with an admin side for managing trips. I made it safer and easier to use: pages that need a login are protected, forms catch mistakes before saving, errors are explained clearly, and trips can be deleted.
  • Angular
  • Node.js
  • Express
  • MongoDB

Enhanced with an Angular route guard for protected admin pages, an improved login flow, stronger Add Trip and Edit Trip validation, clearer error handling, Delete Trip functionality and reusable components.

Algorithms and data structures

CS-300 Course Planner

In plain English: A program that helps students look up college courses and their prerequisites. I made searching much faster by changing how the courses are stored, and made the program handle bad data and typos safely.
  • C++
  • Hash tables
  • Sorting
  • Validation

Enhanced with an unordered_map hash table for faster lookup while keeping the vector for sorted output, plus CSV row validation, duplicate detection, case-insensitive search and safer menu input.
